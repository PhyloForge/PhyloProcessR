# PhyloProcessR tutorials

These tutorials describe the supplied workflows and the principal analysis
functions. The tutorials are part of the main repository. Each software
release therefore includes the applicable tutorial version.

Read the tutorials in this order:

1. [Install PhyloProcessR](installation.md)
2. [Configure a project](configuration.md)
3. [Run the workflows](workflows.md)
4. [Assess the results](assess-results.md)
5. [Integrate legacy data](legacy-integration.md)

For a small complete analysis, use the
[seven-sample laptop example](../../examples/laptop-example/README.md). The
example uses 40 target markers and includes expected outputs.

## Documentation language

The tutorials use simplified technical English based on ASD-STE100 principles.
Instructions use short active sentences, consistent terms, and explicit
conditions. Function names, parameter names, file names, and software names
keep their exact technical spelling.

The package help pages are the authority for function arguments. In R, use:

```r
help(package = "PhyloProcessR")
?functionName
```
